# RouteOS · paquetes de mapa

Paquetes sin conexión para la app RouteOS (GPS offline). La app los baja desde **Mapas → Descargar**;
también se pueden abrir a mano con RouteOS.

- `Nicaragua.routeos` — mapa, red de calles para rutas, búsqueda y rutas de bus.
- `Nicaragua-relieve.routeos` — sombras de cerros y curvas de nivel cada 20 m.
- `catalogo.json` — lista que lee la app (última publicación).

Datos: © colaboradores de [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL),
lugares de [Overture Maps](https://overturemaps.org) (CDLA-Permissive-2.0),
elevación de [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/) (Mapzen; SRTM y otros).
